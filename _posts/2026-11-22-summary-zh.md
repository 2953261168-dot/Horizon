hackernews · valyala · 11月21日 17:08 · [社区讨论](https://news.ycombinator.com/item?id=50591260)

**「背景」** gopgext 是一个项目，它允许开发者使用纯 Go 代码构建 PostgreSQL 扩展。这个项目支持各种 SQL 功能，并能够与 Go 标准库集成。开发者可以通过标记函数为 //gopgext:function 来将其转换为 SQL 函数，gopgext 会自动生成必要的 C 代码、安装脚本和控制文件。项目支持的标准库包括 fmt、regexp、encoding/、crypto/\*、maps、generics、iterators、defer/recover 等。此外，它还支持将 Go 中的字符串、数字、数组、NULLs、集合、行、时间戳、UUIDs 和 JSON 映射到 SQL 类型。gopgext 还允许开发者编写触发器、聚合函数、GiST、GIN、SP-GiST 和 BRIN 索引类、索引访问方法、外部数据包装器和查询钩子。该项目已经在 PostgreSQL 的 contrib 模块（如 pgcrypto、hstore、pg\_stat\_statements、cube 等）上进行了测试，并能够通过上游的回归测试。gopgext 与 Go 标准库的集成和其在 TinyGo 上的运行能力使其特别吸引人。

**「影响」** 对于普通开发者来说，gopgext 项目提供了一个使用 Go 语言创建 PostgreSQL 扩展的新方法。这意味着开发者可以更轻松地利用 Go 的强大功能来构建数据库扩展，而无需编写大量的 C 语言代码。这种方法的引入可能会简化数据库开发过程，尤其是在需要快速迭代和测试新功能时。此外，gopgext 支持 TinyGo，这意味着扩展可以在资源受限的环境中运行，如嵌入式系统或物联网设备。然而，由于该项目社区讨论不多，可能意味着其实用性和可靠性尚未得到广泛验证。

**「背景信息」** 这篇文章讲述了一位用户发现他的显示器（苹果 Studio Display XDR）显著降低了他的下载速度。这位用户拥有 2.5G 的对称互联网线路，但他的下载速度只有 600Mbps，而不是预期的 2.5Gbps。经过调查，他发现这个问题是由于显示器中的 USB-C 到以太网适配器导致的。当适配器直接连接到 MacBook 时，下载速度可以达到 2.3Gbps，但连接到显示器时，速度会下降到 600Mbps。用户尝试了不同的适配器和驱动程序，最终发现更换了一个具有更高 bMaxBurst 值的适配器后，问题得到了解决。

### [新型电极阵列有望恢复听力](https://www.nature.com/articles/s41467-026-79747-4) ⭐️ 8.0/10

一种新型的超柔性电极阵列在听觉脑干植入中展现出恢复听力的潜力，尤其对那些不适合植入耳蜗的病人来说是一个好消息。

rss · Nature Communications · 11月22日 00:00

**「背景」** 听觉脑干植入（ABI）是一种可以恢复听力的高科技植入物，它针对耳蜗核（CN）。这种植入物可以帮助那些不适合耳蜗植入的患者。然而，传统的 ABI 使用表面电极阵列，由于空间分辨率有限和音调访问受限，导致结果高度可变。这项研究开发了一种基于高密度、超柔性植入式神经电极阵列（uFINE）的穿透 ABI。在正常听力大鼠中，uFINE 在 CN 和下丘（IC）中映射了从 0.5 到 32 kHz 的频率调谐。通过 uFINE 选择性刺激 CN 可以引起与声学音调拓扑学密切匹配的 IC 反应，IC 调谐宽度与音调引起的反应相当，并且这些反应在超过 136 天内保持稳定，观察到最小的胶质化。每日连续的 CN-IC 微刺激逐渐将 CN 引起的 IC 反应峰值的位置移向目标 IC 刺激位点，这与使用依赖性可塑性一致。这些发现表明，uFINE 能够在广泛的频率范围内实现高分辨率、音调拓扑学精确和长期稳定的 CN 刺激，同时造成最小的组织损伤，突显了其在增强 ABI 介导的听力恢复方面的潜力。

**「影响」** 这项研究对于普通人的生活有着重要的意义。它意味着，对于那些因为耳蜗结构异常或耳蜗神经问题而不适合进行耳蜗植入手术的患者，现在有了新的希望。这种新型的电极阵列能够更精确地刺激听觉脑干，从而提高听力恢复的效果。对于年轻人来说，这意味着他们有更多机会通过科技手段改善生活质量，尤其是在面对听力障碍时。
